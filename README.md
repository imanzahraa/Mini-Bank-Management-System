A lightweight Java Swing + MySQL desktop application for managing basic banking operations. Built with focus on JDBC integration, event-driven programming, and GUI design using NetBeans.

🚀 Features

Create new user accounts with personal details

Secure login and logout

Initial deposit setup during account creation

Deposit and withdraw funds

Real-time balance updates

Transaction history table (stored in MySQL)

Profile view with stored account details

🧩 Tech Stack

Language: Java (JDK 21+)

GUI Framework: Java Swing

Database: MySQL (XAMPP or local server)

IDE: NetBeans

JDBC Driver: mysql-connector-java

🛠️ Setup

Clone the repository:

git clone https://github.com/yourusername/MiniBankManagementSystem.git


Import the project into NetBeans.

Set up the MySQL database:

Create a database named accountdb

Import the provided SQL file or manually create required tables

Update your database credentials in the connection file.

Run the project and start banking!

📚 Learning Goals

Integrating Java applications with MySQL

Implementing CRUD operations using JDBC

Designing interactive GUIs with Swing

Managing multiple frames and event listeners
